# ig-caption
```bash
python3 caption.py caption.txt          # إنستغرام
python3 caption.py caption.txt --yt     # يوتيوب (≤100 حرف مع الهاشتاقات، بدون إيموجي، #Shorts)
```
## القواعد
- أول سطر = الهوك. الجملة لازم تخلص قبل 125 حرف.
- قالب القناة: سؤال/فكرة + سطر بيكسر التوقع + «اكتبوا جوابكم بالتعليقات 👇» + هاشتاقات (`#Quizzawi #تحدي` + هاشتاق الموضوع).
- يوتيوب: نسخة منفصلة، بدون إيموجي، وبـ `#Shorts`، مجموعها ≤100 حرف.
- 3–5 هاشتاقات بالكثير.
- اعطي نسختين: إنستغرام/فيسبوك/تيك توك ونسخة يوتيوب. شغّل الأداة على كل وحدة.
