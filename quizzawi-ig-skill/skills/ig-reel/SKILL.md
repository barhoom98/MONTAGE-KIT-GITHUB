# ig-reel
بيحوّل فكرة وحدة لريل بيكمّله الناس للآخر. الأداتين اللي بهالمجلد بتشتغل فعلاً، استعملهم ولا تقدّر بالعين.

```bash
python3 hookscore.py hooks.txt           # رتّب الهوكات
python3 beats.py script.txt --target 30  # وقّت السكربت
```

## قبل ما تكتب
1. اقرأ `~/.claude/instagram/voice.md` إذا موجود (صوت القناة). إذا لأ، اطلب 3 ريلز للمستخدم واكتب الملف منهم.
2. اقرأ `hooks.json` (12 صيغة).
3. إذا الفكرة ناقصة: سؤال واحد مجمّع (شو صار؟ لمين؟ شو الرقم؟).
4. إذا `~/.claude/instagram/swipe.md` موجود اقراه: هو دليل المستخدم على اللي شغّال بمجاله.

## الشكل
```
0:00–0:02  الهوك   الجملة المحكية + جملة الشاشة (مختلفتين). حركة من أول فريم.
0:02–0:07  الرهان  ليش هاد يهمّ اللي بيشوف؟ سطر واحد.
بعدين     الجسم   فكرة وحدة لكل بيت، والصورة بتتغير كل بيت.
آخر 3ث    الجواب  اللي وعدت فيه الهوك + طلب واحد بس.
آخر سطر   اللوب   كرّر كلمة من الهوك.
```
المدة: 25–45 ثانية. بدون ترحيب أبداً.

## الخطوات
1. **3 هوكات** من 3 صيغ مختلفة (مش 3 صياغات لنفس الصيغة).
2. **قيّمهم** بـ `hookscore.py`. إذا الأعلى تحت 50 ما عندك هوك.
3. **اكتب السكربت** على الأفضل، بلغة محكية قصيرة.
4. **وقّته** بـ `beats.py` وصلّح كل ملاحظة.
5. **افحص اللهجة** بـ `/ig-lahja` قبل ما تعرضه.
6. اعرض: الهوكات مع العلامات، السكربت، النص على الشاشة، ورقة التوقيت. **ما بنشر شي**: المستخدم بينشر.
