# ig-lahja
```bash
python3 lahja.py text.txt
```
## القواعد المعتمدة
- **أردني فقط.** هَسَّة (مش هلّق/هلأ)، مِش (مش مو)، عَشَان، إِشِي.
- **القاف بتنكتب «ق»**. ممنوع «گ» و«ئ».
- **الثاء بالأرقام:** ثَلَاث، ثَلَاثَة، ثَمَنْيِة، اثْنِين، أَكْثَر، كْثِير.
- **الضمائر بالميم:** فِيكُمْ، مَعْكُمْ، جَوَابْكُمْ.
- وَاحَد (مش وَاحِد)، خَمِسْطَعْشَ، سِطَّعِش.
- **التشكيل على اللفظ الأردني** مش الإعراب. بدون حركات إعراب بآخر الكلمات، **استثناء: «أَبَداً»** بالتنوين.
- اسم القناة بالفويس **«كْوِيز زَاوِي»** (على الشاشة Quizzawi).
- **بدون ترحيب** («أهلين فيكم» ممنوعة).
الأداة بتلقط الأغلب، لكن آخر قرار للمستخدم لأنه بيسمع الصوت. ما تغيّر نص المستخدم المعدّل أبداً.
