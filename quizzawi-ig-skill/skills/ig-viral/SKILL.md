# ig-viral
```bash
python3 swipe.py captured.tsv --out ~/.claude/instagram/swipe.md
```
## الفكرة
**المشاهدات الخام مش دليل.** حساب 2 مليون بـ 400 ألف مشاهدة كان يومه عادي. حساب 4 آلاف بـ 400 ألف لقى شي ممكن ينقلد. فالترتيب بـ **مضاعف** = مشاهدات الريل ÷ متوسط الحساب. فوق 3x إشارة. تحت 1.5x يوم عادي.

## الخطوات
1. اطلب 6–12 حساب (أو اقترح واطلب موافقة) بحجم قريب من حساب المستخدم (حتى 10 أضعاف).
2. المستخدم بيفتح الحسابات بمتصفحه هو، وإنت بتقرا اللي بيبعته (أرقام، هوكات). **ما بنطلب باسوورد ولا بنعمل سحب آلي.**
3. لكل ريل سجّل: الحساب، المتابعين، متوسط مشاهدات الحساب، مشاهدات الريل، الهوك، الصيغة (من `../ig-reel/hooks.json`) بملف TSV.
4. شغّل `swipe.py` واكتب ملاحظات: أي صيغة تكررت بين الإشارات؟
5. ما تنسخ نص حدا: اقتبس **الصيغة**، واكتب النص بصوت القناة.
