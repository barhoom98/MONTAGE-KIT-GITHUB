# مؤثرات الصوت

ملفات WAV غير مخزنة مسبقًا في المستودع؛ ينشئها `tools/generate_assets.py` محليًا. يلزم Python 3، ولا تحتاج العملية إلى حزم إضافية أو اتصال بالإنترنت.

الملفات الناتجة أصلية، أحادية القناة، PCM خطي 16-bit، بمعدل 48 kHz: `whoosh` للانتقال، `riser` للتصعيد قبل القطع، `impact` للكشف أو الضربة، `snap` للقطع الإيقاعي، و`sparkle` للتفاصيل اللامعة. خفّض مستوى المؤثرات في المكس النهائي.
