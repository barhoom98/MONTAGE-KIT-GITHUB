# قوالب Remotion للقنوات

قوالب فيديو جاهزة بالكود لريلز 1080×1920. كل فيديو عبارة عن ملف JSON صغير فيه المحتوى، والقالب بيطلّعه فيديو كامل بهوية القناة.

| القالب | القناة | شو بيعمل |
|---|---|---|
| `QuizReel` | كويزاوي | لوغو ← سؤال و4 خيارات (1 2 3 4) ← مؤقت ← كشف الجواب ← التحليل ← دعوة للتعليق |
| `AyahReel` | ثمرة آية | عنوان ← الآيات بالتلاوة (النص من تنزيل) ← الثمرات ← خاتمة، بدون موسيقى |
| `Tip-Nutrition` · `Tip-Accounting` · `Tip-Gym` | التغذية · المحاسبة · الجيم | هوك ← نقاط مرقّمة بصور ← دعوة للمتابعة |
| `Cover` | كل القنوات | غلاف الريل (صورة) |

## التشغيل أول مرة

بدك Node.js 20 أو أحدث.

```bash
cd remotion
npm i
npm run dev        # بيفتح Remotion Studio وبتشوف كل القوالب وبتعدّل عليها مباشرة
```

## الهوية

- **الألوان:** كلها بملف `src/theme/themes.ts`. ألوان كويزاوي هي المعتمدة، والباقي مقترحة غيّرها براحتك.
- **اللوغو:** حط صورة PNG شفافة بـ `public/brand/` ومرّر مسارها بـ `"logo": "brand/quizzawi.png"`. بدون لوغو بيطلع اسم القناة مكتوب.
- **صوت المقدمة لكويزاوي:** حط نفس صوت المقدمة القديم بـ `public/brand/intro.wav` ومرّر `"introSfx": "brand/intro.wav"`.
- **الخطوط:** Cairo للنصوص وAmiri Quran للآيات، محلية بـ `public/fonts` ومرخصة OFL (مسموحة تجارياً).
- **المؤثرات:** `public/sfx` منسوخة من `montage-kit/sfx` (CC0).

## إنتاج فيديوهات (دفعة كاملة)

1. اعمل ملف JSON لكل فيديو بمجلد القناة، مثلاً `data/quizzawi/002-xxx.json` (انسخ أول ملف وعدّل عليه).
2. شغّل:

```bash
npm run batch -- data/quizzawi
```

بيطلع كل فيديو بـ `out/quizzawi/` مع غلافه، وعلو الصوت موحّد على ‎-14 LUFS. الفيديوهات الموجودة بيتخطاها، وإذا بدك يعيدها ضيف `--force`.

أي خاصية ما بتكتبها بالملف بتاخذ القيمة الافتراضية من `src/Root.tsx`.

## التعليق الصوتي والترجمة كلمة بكلمة

السكربت بيولّد الصوت من ElevenLabs مع توقيت كل حرف، وبيطلّع منه ملف ترجمة جاهز:

```bash
export ELEVENLABS_API_KEY=xxxx
npm run captions -- --voice VOICE_ID --text scripts/q2-question.txt --out public/vo/q2-question
```

بيكتب `public/vo/q2-question.mp3` و`public/vo/q2-question.captions.json`. بعدها بملف الفيديو:

- كويزاوي: `"voiceQuestion"` و`"captionsQuestion"` لصوت السؤال، و`"voiceAnswer"` و`"captionsAnswer"` لصوت الجواب.
- النصائح: `"voiceover"` و`"captions"`.
- ثمرة آية: `"voiceLessons"` و`"captionsLessons"` لشرح الثمرات.

المشهد بيطول لحاله على قد الصوت. الترجمة بتطلع بدون تشكيل (أوضح للقراءة)، وإذا بدك التشكيل ضيف `--keep-tashkeel`.

## ثمرة آية والنص القرآني

- **النص ما بينكتب يدوي أبداً.** بتكتب رقم السورة والآيات بس (`sura`, `ayaFrom`, `ayaTo`)، والقالب بيسحب النص حرفياً من `public/quran/quran-uthmani.txt`.
- **المصدر:** مشروع تنزيل (tanzil.net)، الرسم العثماني. التفاصيل وبصمة الملف بـ `public/quran/SOURCE.md`.
- **التحديث:** workflow ‏`fetch-tanzil` بـ GitHub Actions بينزّل النص ويتحقق منه (6236 آية، 114 سورة، 15 سجدة). بتقدر تشغله يدوياً من تبويب Actions، أو محلياً: `npm run fetch:quran`.
- **شرط تنزيل:** لازم تذكر المصدر. القالب بيكتبه على الشاشة، وضيف كمان بوصف كل فيديو: «النص القرآني: مشروع تنزيل tanzil.net».
- **التلاوة:** من مستودع `thamarat-aya-audio`. إذا الآية مش موجودة هناك، ضيفها لـ `verses.txt` بنفس المستودع وبتنزل لحالها.
- **البسملة:** بأول آية من السورة بتطلع بسطر لحال فوق الآية (العرض بس، النص نفسه ما بيتغير).
- **الثمرات:** راجعها مع مختص قبل النشر.

## نصائح

- خلّي `"showSafeArea": true` وقت التصميم: بيلوّن الأماكن اللي بتغطيها أزرار تيك توك وإنستغرام.
- الأرقام مع رموز زي `#24` بتنقلب بالعربي وبتصير `24#`. اكتب «رقم 24» بدالها.
- الصور والفيديوهات من مكتبة Magnific (ستوك حقيقي) بتمشي أحسن من صور الذكاء الاصطناعي للتغذية والجيم.

## الترخيص

Remotion مجاني للأفراد والفرق لحد 3 أشخاص، وأكثر من هيك بدها رخصة شركة. الخطوط OFL، والمؤثرات CC0، ونص القرآن حسب شروط مشروع تنزيل.
