# Montage Kit — 2026

حزمة مونتاج أصلية وخفيفة بطابع عصري ومرح، قابلة للاستخدام مع برامج تحرير مختلفة. الأصول هنا أصلية وليست من حزم تجارية أو مصادر خارجية.

## محتويات الحزمة

- **فلاتر ألوان:** أربعة ملفات `.cube` قياسية جاهزة للاستيراد: `golden-hour`, `teal-pop`, `soft-candy`, و`night-neon`. ينشئ المولّد نسخًا ثلاثية الأبعاد أدق منها.
- **مؤثرات صوتية:** 167 ملف WAV جاهزة في `montage-kit/sfx/` (انتقالات وضربات وتصاعد وواجهات وميمز وطبول وأجواء)، بالإضافة إلى مولّد ينشئ خمسة مؤثرات أساسية: `whoosh`, `riser`, `impact`, `snap`, و`sparkle`.
- **طبقات ضوئية:** ثلاثة تراكبات SVG شفافة: تسريب ضوء دافئ، توهج سماوي، وخطوط ضوئية منشورية.
- **حركات وانتقالات:** وصفات FFmpeg وإرشادات تطبيقها في محررات الفيديو.

## العدّة الكاملة (`montage-kit/`)

مجلد [`montage-kit/`](montage-kit/) يضم العدّة الكاملة مع أداة تطبّقها على الفيديو بأمر واحد (`edit.py`): 99 حركة ومؤثرًا بصريًا، وانتقالات مخصصة وكلاسيكية بين المقاطع، و167 مؤثرًا صوتيًا، و71 فلتر ألوان `.cube`، و54 طبقة ضوئية بصيغة MP4. الدليل الكامل بأسماء كل العناصر وخياراتها في [`montage-kit/README.md`](montage-kit/README.md).

ستيكرات النيون المتحركة (حزمة `neon/` والأداتان `overlay.py` و`export_all.py` وملفات `assets/png` و`assets/webm`) في جذر المستودع، ووثائقها في [`STICKERS.md`](STICKERS.md). خيار `--sticker` في `edit.py` يعتمد عليها، فأبقِ `neon/` و`overlay.py` في الجذر.

شغّل الأوامر من جذر المستودع:

```bash
pip install -r montage-kit/requirements.txt   # ويلزم ffmpeg
python3 montage-kit/edit.py list
```

## إنشاء ملفات الصوت والفلاتر

يتطلب Python 3 فقط، ولا يحتاج إلى تثبيت حزم أو الاتصال بالإنترنت. ينشئ ملفات الصوت ويستبدل LUTs المضمنة بنسخ 3D:

```bash
python tools/generate_assets.py
```

يكتب ملفات LUT في `assets/luts/` وملفات WAV في `assets/audio/`.

## الاستخدام

- **LUT:** استورد ملف `.cube` في محررك وطبّقه على طبقة تعديل. ابدأ بقوة 25–60% واضبط التعريض وتوازن الأبيض أولًا.
- **طبقة الضوء:** استورد SVG، وضعه فوق الفيديو بمزج Screen أو Add أو Lighten وشفافية 15–45%. إذا لم يدعم المحرر SVG، حوّله إلى PNG شفاف.
- **الصوت:** ضع `whoosh` أو `snap` عند القطع، و`impact` عند لحظة الكشف، و`riser` قبل الانتقال. خفّض المؤثرات تحت الحوار والموسيقى.
- **الحركة:** راجع `presets/ffmpeg-recipes.md` لوصفات قابلة للتعديل. غالبًا تكفي انتقالات مدتها 0.25–0.6 ثانية؛ نوّع الإيقاع ولا تستخدم انتقالًا قويًا مع كل قطع.
